# 高考复习系统

基于 React + TypeScript 的高考复习辅助 Web 应用。

## 技术栈
- React + TypeScript
- Vite 构建
- 响应式设计（移动端优先）

## 项目结构
- `src/` — 源码
- `components/` — 可复用组件
- `hooks/` — 自定义 React hooks
- `services/` — API 服务层
- `api/` — 后端 API 路由
- `docs/` — 文档
- `dist/` — 构建产物

## 开发
```bash
npm install
npm run dev
```

## 构建
```bash
npm run build
```
